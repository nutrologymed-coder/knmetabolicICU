KNmetabolicUTI – GitHub Pages Deploy (Quick)

1) Create a new repo (public): knmetabolicuti
2) Upload these files to the repo root:
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - icon-512.png

3) Enable Pages:
   Settings → Pages → Deploy from branch → main / (root)

4) Your app URL:
   https://<your-user>.github.io/knmetabolicuti/

iPhone install:
Safari → Share → Add to Home Screen
