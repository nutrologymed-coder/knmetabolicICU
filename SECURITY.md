# Política de segurança

## Reportar uma vulnerabilidade
Use **GitHub → Security → Report a vulnerability** (aviso privado) em
https://github.com/nutrologymed-coder/knmetabolicICU/security/advisories/new.
Não abra issue pública nem inclua dados de pacientes.

Meta de resposta: confirmação em 3 dias úteis; correção ou mitigação conforme severidade.

## Erros clínicos
Resultados incorretos de calculadoras devem ser reportados pelo template **"Erro clínico em calculadora"** (use apenas valores fictícios).

## Escopo
Site estático, workflows de CI/CD, migrações de banco e documentação deste repositório. Detalhes em `docs/security.md`.
